COLLECTOR FINAL UI ORDER FIX v720

What this fixes:
- Back/Next was appearing before Crop Survey and Livestock Survey.
- Crop/Livestock buttons looked misplaced and crowded.
- The warning "Draw a point or polygon first..." was showing at the wrong time.
- Entries and Offline Save & Sync were crowding the collector screen.
- Offline & Basemaps is kept as one collapsed card.
- Settings, Operations and Field Readiness are hidden from the normal collector view.

Expected Start Survey order:
1. Survey Name
2. Crop Survey
3. Livestock Survey
4. Back / Next only after needed

Install:
1. Copy all files into your frontend folder.
2. Replace existing files.
3. Open WELCOME.html?screen=collector&v=720
4. Press Ctrl + F5.
5. If old layout remains, clear site data and restart Live Server.
