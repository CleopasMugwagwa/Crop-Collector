FRONTEND v620 SECOND PLOT HELPER

Fixes:
- Adds a Second Plot / Same Farmer Helper in the collector form.
- After saving a record, farmer/owner/contact/admin details are stored as reusable context.
- For the next plot, click "Use Previous Farmer Details".
- The collector then fills only plot-specific details: crop/livestock type, boundary, area, condition, growth stage, notes, photo.
- Does not change field questions.

Install:
1. Copy all files into the frontend folder.
2. Replace existing files.
3. Open WELCOME.html?screen=collector&v=620
4. Press Ctrl + F5.
