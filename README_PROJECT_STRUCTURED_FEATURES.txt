Important about Shapefile:
Real shapefile output should be generated by FastAPI as a ZIP containing .shp, .shx, .dbf, .prj.
The frontend button currently downloads shapefile_export_request.json unless you connect it to your backend shapefile endpoint.

Install:
1. Backup your current frontend folder.
2. Copy all files from this ZIP into your frontend folder.
3. Replace WELCOME.html and admin-dashboard.html.
4. Restart Live Server.
5. Open:
   WELCOME.html?screen=collector&v=520
   admin-dashboard.html?v=520
6. Press Ctrl + F5.

Validation explanation:
In the current frontend test version, validation updates localStorage so you can test the workflow immediately.
For production, the same actions should call FastAPI endpoints such as:
PATCH /api/v1/records/{id}/validate
PATCH /api/v1/records/{id}/reject
PATCH /api/v1/records/{id}/correction
